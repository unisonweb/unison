Unison.MCP.Echo

Description

The reply to a transcript repeats it, with UCM's output filled in. The long unison blocks are what the caller wrote a moment ago, so by default they are left out, with a note of where they are.

Synopsis
  • maxEchoedLines :: Int

Documentation

maxEchoedLines :: Int Source #

A unison block of more lines than this is not repeated in the reply.

elideLongBlocks :: Int -> Text -> Text -> Transcript -> Transcript Source #

Replace the code of each inline unison block of more than the given number of lines with a note of where it is: which code block it is, and which lines of the source. Takes what to call the source, the source, and the transcript that was run. If the blocks can't be matched up with the source, nothing is changed.
