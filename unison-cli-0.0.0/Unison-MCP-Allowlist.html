Unison.MCP.Allowlist

Description

Which UCM commands each of the MCP transcript tools allows.

The tiers nest: a tool allows every command at or below its own tier. The tier of a command is the least powerful tool that may run it, and a command that isn't listed (including any command added later) is All.
