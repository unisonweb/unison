Description

The learn tool and the server instructions. Both come from the Markdown files in docsmcplearn, which are embedded in the executable when it is compiled and parsed when the server starts, so nothing here reads a file or runs a tool at run time. See docsmcplearn/README.md for how they are organized.

data Guide Source #

The topics, and the server instructions.

parseGuide :: [(FilePath, Text)] -> Guide Source #

Parse the guide, given the files (their paths relative to the directory, and their contents).

  • instructions.md is the server instructions.
  • Every other .md file but README.md is a topic, whose path is the file's path without .md. index.md is the root.
  • Under a heading called Detail (outside of code fences) is the topic's detail; what comes before is its summary.
  • HTML comments on lines of their own are dropped.

instructions :: Guide -> Text Source #

The server instructions.

learn :: Guide -> Text -> Either Text Text Source #

Look up a topic by path. Left is a message to show when there is no such topic.

The path is names separated by /, like ucm/merge. An empty path is the overview. Adding /detail gives a topic's detail. A leading learn: (from a link) is ignored.
