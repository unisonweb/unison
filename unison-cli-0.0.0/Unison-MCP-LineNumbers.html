Unison.MCP.LineNumbers

Description

UCM quotes the line it is complaining about with a number that counts from the start of the code block it was given (2 | double n = n * "two"). Rewrite those numbers to count from the start of the transcript, so that the caller can go straight to the line without adding anything up.

Only messages about the transcript's own unison blocks are touched. Messages about a file that a command loaded, like load foo.u, already have that file's line numbers and are left alone.
