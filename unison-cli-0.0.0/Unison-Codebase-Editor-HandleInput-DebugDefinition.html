intermediateCode :: Bool -> HashQualified Name -> Cli () Source #

Show the intermediate code (ANF) of a term, the other terms of its cycle, and the lambdas lifted out of them; optimized when the flag is set. The term can be one of the latest typechecked file's, not added yet: as for run, the file's names shadow the codebase's, and its code is looked up before the codebase's.
