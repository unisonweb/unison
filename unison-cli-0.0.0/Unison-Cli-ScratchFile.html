Unison.Cli.ScratchFile

Description

Scratch files for the actions that must produce a branch that compiles (update, delete, merge, pull and upgrade). When one of them can't, it leaves the user on a temporary branch, with a scratch file of the definitions that need fixing. That file gets its own name, like merge-bob-into-alice-a0458b71.u, rather than reusing scratch.u, so that it is unmistakable which file goes with which action and branch.

scratchFileName :: Text -> [Text] -> [Text] -> Text Source #

scratchFileName action words parts is <action>-<words>-<shorthash>.u. The words say what the action is about, like the branches involved (they are made safe for a file name, and shortened). The short hash (8 characters) is of the action, the words and the parts: the arguments, and the hashes of the branches involved. The same action on the same branches therefore always gets the same file name, and a different one gets a different file name.

writeActionScratchFile :: Text -> [Text] -> [Text] -> Text -> Cli FilePath Source #

Write contents to the scratch file for action (see scratchFileName), in the directory of the latest file (or the current directory), and make it the latest file. Returns the file's path.
