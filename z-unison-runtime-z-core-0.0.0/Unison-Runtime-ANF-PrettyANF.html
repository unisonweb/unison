Description

Shows intermediate code (ANF) in a syntax that resembles Unison's, for the ir and `ir.optimized` commands in ucm. The syntax is explained, with a reference table, in unison-srctranscriptsidempotent/ir.md.

prettyIRCombs :: IRNames -> Reference -> [Symbol] -> [(Word64, SuperNormal Reference Symbol)] -> Pretty SyntaxText Source #

The combinators of a group by index, as the runtime numbers them: the entry at 0, the local functions at n * 2^16 (named by the given variables, which is how the bodies refer to them), and those the loader's rewrites add (Unison.Runtime.MCode.Explode): specialisations, a product-return worker and join points. The entry is the definition of the reference with the local functions in its block; each added combinator is a definition of its own, named for its index (indexLabel).
