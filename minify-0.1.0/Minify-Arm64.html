decodeFrom :: Hooks -> Word64 -> IO () Source #

Recursive-descent decoding from a label within a Haskell definition. GHC's native code generator emits a closed set of address-carrying forms: adrp+add (adjacent) for a label, adrp+ldr for a GOT slot, b for jumps and tail calls, bl for foreign calls, and b.cond, cbz, tbz within a procedure. Anything else that names an address is an anomaly.

sweepFixed :: Bool -> Hooks -> Word64 -> Word64 -> IO () Source #

A linear sweep of fixed code for what it refers to. An adrp is paired with its consumers when the register's uses can all be followed, and each target pinned; otherwise the page is pinned. A target in code is also a label: GHC code lies in fixed regions too (a module's unnamed local closures follow whatever symbol precedes them, the C main of the program's own module for one), and the info table before such a label holds an SRT offset that must follow its closure.

In a linker's erratum veneer (veneer), the target of a b is a label even without a table. The linker moved one instruction of a block into the veneer, put a b to the veneer in its place, and the veneer's b returns to the rest of the block. Decoding stops at the first b, so without this label the rest of the block, and whatever only it reaches, would never be decoded: its references would not be rewritten, and what they point at could move or be removed while it stays put.
