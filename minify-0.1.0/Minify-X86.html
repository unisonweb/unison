Minify.X86

Description

x86-64: an instruction-length decoder that also says where an instruction's address-carrying fields are, the recursive-descent decoding of a Haskell definition (with GHC's jump tables), the linear sweep of fixed code, and the abort stub.

GHC's native code generator refers to addresses through rel32 branches and calls, RIP-relative operands, and in a non-PIE executable through sign-extended 32-bit immediates and displacements (the small code model). Switches with dense cases compile to a jump table of displacements from the table (64-bit, in the text section, on Darwin; 32-bit, in read-only data, on Linux with PIC) or of absolute addresses (in read-only data, without PIC).

decodeFrom :: Hooks -> Word64 -> IO () Source #

Recursive-descent decoding from a label within a Haskell definition. GHC emits a switch's table lookup as one contiguous sequence, so a lea of a table is recognised by looking at the instructions after it: lea T(%rip), r; add (r, i, 8), r; jmp *r (64-bit displacements, on Darwin) or lea T(%rip), r; movslq (r, i, 4), c; add c, r; jmp *r (32-bit displacements, on Linux with PIC). Without PIC the table holds absolute addresses and is read directly: jmp *T(, i, 8).

scanTables :: Hooks -> [(Word64, Int, Bool)] Source #

Every jump table a definition's bytes name, found by scanning them for the lookup idiom rather than by reaching the code: a table's entries can only be read once the tables that follow it are known, and the code that names a table may itself be reachable only through another table. Returns (table address, entry size, relative).

tableEntries :: Hooks -> Word64 -> Int -> Bool -> IO () Source #

Reads a jump table's entries, once decoding has settled: each is a reference from the table to a block, and a label to decode from. Entries are read while they are plausible: a displacement that is zero (a missing case) or negative and lands in the definition, or an absolute address in it; never past the next table, and never one that lands inside an instruction already decoded, which only a misread entry does.

sweepFixed :: Hooks -> Word64 -> Word64 -> IO () Source #

A linear sweep of fixed code: every address it names inside a Haskell definition is pinned. A byte that decodes as nothing is skipped.

stubCode :: Word64 -> Word64 -> Maybe Word64 -> [Word8] Source #
