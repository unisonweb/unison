plan :: Analysis -> Int -> Bool -> [Role] -> Maybe (Word64, Word64) -> Bool -> Maybe (Word64, Word64) -> Either String Plan Source #

The second argument caps the number of holes (segments added); the third puts the extra code-segment pieces after the data pieces in the load commands, so that the data segments keep indices dyld's opcodes can express however many holes the code segment has (Mach-O only). packRoles names the sections whose movable definitions are packed first-fit; the rest keep their order (a debugging knob).

newAddrOf :: Analysis -> Plan -> Word64 -> Maybe Word64 Source #

The new address of an old one: moved with its definition, or unchanged when it lies in nothing that moves. Nothing for an address inside a definition that is not kept.

The file offset of a new address in the output.
