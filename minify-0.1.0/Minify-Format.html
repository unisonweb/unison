Minify.Format

Description

What the tool needs to know about an executable regardless of its file format: its segments and sections, its symbols, where the loader fixes pointers up, and which parts play which role in compaction. The Mach-O and ELF readers each produce a Loaded.

ghcLocalLabel :: ByteString -> Bool Source #

Whether a Mach-O local symbol's name is one GHC gives a local label on Darwin: L, a unique of letters and digits, and a kind suffix (_Lc4py_info, _Lg1Kz_closure). C's own local names have words separated by underscores (_mark_closure) and no L. ELF readers use the symbol's type instead: GHC's local labels are untyped there.
