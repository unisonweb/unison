parseHsName :: ByteString -> Maybe HsName Source #

Splits a linked symbol name (with its leading underscore on Darwin, without on ELF). A module component starts with an uppercase letter; a binding and a module never contain an underscore, since z-encoding escapes it, so the components are unambiguous.
