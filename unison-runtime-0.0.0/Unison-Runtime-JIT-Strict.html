Unison.Runtime.JIT.Strict

Description

The strict building blocks of the code generator: packed text, strict pairs, and the few operations on them that Unison.Util.Text and Unison.Util.Deque don't have.

The generator's state and everything it produces are made of these, of Deque (a finger tree with no laziness anywhere) and of strict record fields, so that forcing the state to weak head normal form forces all of it: no thunk over the text of a module outlives the step that made it, and the text is packed from the start (a Text is a rope of packed chunks, so appending to a long one doesn't copy it).
