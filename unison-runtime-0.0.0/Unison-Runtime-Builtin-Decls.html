Unison.Runtime.Builtin.Decls

Description

DO NOT EDIT. Generated by unison-runtimescriptsgen-builtin-decls.sh.

The references and constructor numbers of the builtin declarations (Unison.Builtin.Decls) and the order of the builtin types (Unison.Builtin), as constants, so that the runtime needs neither the declarations nor the hashing that makes their references (unison-runtimescriptsGenBuiltinDecls.hs says why). The test Unison.Test.Runtime.BuiltinDecls fails when they no longer match their sources, and says to run the script.
