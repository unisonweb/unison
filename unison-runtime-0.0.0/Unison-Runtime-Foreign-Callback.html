Unison.Runtime.Foreign.Callback

Description

Turning a Unison function into a C-callable function pointer, so that C code can call back into Unison. This is the mirror image of the dynamic call in Unison.Runtime.Machine: there, Unison stack values are marshalled into a libffi argument buffer and a C function is called; here a C caller fills an argument buffer, a libffi closure invokes a single generic Haskell entry point, we decode the arguments directly onto a Unison stack, run the Unison function, and marshal its result (left on the stack) back into the C return slot.

The Haskell libffi package does not expose the closure API, so the three ffi_closure_* entry points are imported directly (they are linked via that package already), as is done for ffi_prep_cif_var in Unison.Runtime.Foreign.Dynamic.

Running the Unison function is supplied by the caller (a Stack -> (Stack -> IO ()) -> IO () action, in practice a partially-applied evaluator entry) so that this module does not depend on the evaluator. Arguments are written straight to the stack rather than through an intermediate [Val], so the marshalling allocates nothing beyond the stack itself.

type RunCallback = Stack -> (Stack -> IO ()) -> IO () Source #

Runs the Unison function from a callback: the given stack already holds the decoded C arguments (pushed in parameter order); apply the function to them and hand the result stack to the continuation (the result on top). Supplied by the evaluator so this module stays off it. Expected to be synchronous.

mkCallback :: FFSpec -> RunCallback -> IO CDynFunc Source #

Build a C-callable function pointer from a Unison function. The FFSpec describes the C signature; run applies the Unison function to the arguments the callback decodes onto the stack. The result is a CDynFunc (so it flows through the same paths as a symbol loaded from a DLL) whose underlying pointer calls back into Unison.

The returned callback holds the Unison function (and anything it closes over) alive until freeCallback is called; using the pointer afterwards is a use-after-free, exactly as with a freed Dynamic pointer.

freeCallback :: CDynFunc -> IO () Source #

Release a callback created by mkCallback: frees the libffi closure and drops the reference keeping the Unison function alive. Safe to call more than once, and a no-op on a CDynFunc that is not a callback (e.g. a DLL symbol, whose finalizer is pure ()).
