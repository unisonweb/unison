Unison.Runtime.JIT.Frames

Description

The frame table, one per JIT. A native caller whose callee exits writes a frame record naming an entry here; the trampoline turns the record into the Push frame the interpreter would have pushed. See unison-runtimesrcUnisonRuntimeJIT/design.md, "Frames: native code records, Haskell builds".

data Frame Source #
