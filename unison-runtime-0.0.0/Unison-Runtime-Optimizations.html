Unison.Runtime.Optimizations

Description

The optimizations a process can switch on or off, all under one environment variable, UNISON_OPTIMIZATIONS: a comma-separated list of names, each on its own or after + (on) or - (off), and the words all and none. Later entries override earlier ones, so none,explode_returns keeps only the return workers. A name the variable does not mention keeps its default, which may depend on the JIT mode (the wide convention and the replacements follow UNISON_JIT). An unknown name is an error, so a misspelling cannot pass as a measurement.

Read once, on first use, like the settings it feeds (Wide, Config, Explode). Every optimization here changes only the code the runtime runs, never a stored value or hash, which is why a stray setting is allowed to take effect (the debugging switches that weaken the runtime stay under UNISON_JIT_DISABLE, read only with UNISON_JIT_DEBUG).
