Unison.Runtime.Render

Description

Prints a runtime value on one line, for programs run without a codebase (unisonrt): its trace output, and the values of its crashes.

Only data prints in full: numbers, characters, text, bytes, lists, records, and constructors, named as the compiled program's constructor table names them (Unison.Runtime.Standalone). Anything else prints as a placeholder: a function as function, a foreign value by its type. Nothing here is Unison syntax that parses back; ucm's printer (Unison.Syntax.TermPrinter, by way of decompiling the value) is the one that does that.
