# 2026-10-11: handler cases that observe the environment

An affine handler case that makes a request of its own, or calls a function, runs natively:
its `InLocal` switches the environment in the context, its `Yield` switches back, and an
exit in between hands the interpreter a `Local` frame record ("Ability requests" in
design.md, "The switch"). Before, such a case exited at its `InLocal` on every request.
Optimized build, `UNISON_JIT=on`; the suite runs with `UNISON_JIT_STATS=1` (compare.py keys
on its compile summary), medians of three; the standalone numbers are without statistics,
medians of two; the interpreter column is one run.

One row added to the suite: a `Store` whose `put` case performs a `Counter.next` of the
handler outside it, 100000 iterations of a `get` and a `put` (100000 outer requests made
from inside a case, 200000 requests in all).

| | interpreter | JIT, in the suite | JIT, standalone |
| --- | --- | --- | --- |
| Store whose put requests an outer Counter, 100000 iterations | 38.3 ms | 14.6 ms | 10.4 ms |

Two more loops, measured standalone only (`scratchpad/aff/v3.md`), with handlers that relay
an `Ask` to the handler outside them and add one, nested N deep:

| | interpreter | JIT |
| --- | --- | --- |
| Ask relayed through 3 handlers, 100000 requests | 37.2 ms | 10.3 ms |
| Ask relayed through 12 handlers, 10000 requests | 9.75 ms | 9.6 ms |

The 12-deep loop shows the bound as it was when measured, `UNISON_JIT_LOCALS` = 8 (raised to
32 the same day: one more pointer per stack per slot, nothing per round trip): an exit hands
back at most that many switched environments, so the ninth nested switch is a call-out, once per request, after
which the eight native switches below it have become `Local` frames and the levels above
run native again. One call-out plus the re-entries of the eight `Let` bodies on the way back
costs about what the interpreter takes for the whole request, so the row is at interpreter
speed; three deep, it is 3.6 times faster.

Exits: the Store row and the 3-deep row take none at the `InLocal` (`UNISON_JIT_STATS=1`
on the development build); the 12-deep row takes exactly one per request.

The other rows are unchanged within noise against [2026-10-11 requests](2026-10-11-requests.md)
(Collatz −6% and Store −5% are within their spread). Compile totals on the suite: 86 → 89
modules for the new row's functions; compile time 1047–1081 → 1034–1067 ms. The round trip
no longer allocates the one-element array that carried the environment: it travels in the
boxed stack's out-area.
