The prompt gives the intended formula (`Order.total +100` is `+95`), so the judges can run it.
- Good run: `merge /bob`, read the conflict file, write one version of the three definitions with the combined behavior and tests (`+95`, `"Total: 95"`), keep `summary` in the loaded file, `load`, `update`, finish on `alice` with no temporary branch. `learn`: `ucm/merge`, `ucm/temporary-branch`, `ucm/scratch-file`.
- Traps: picking one side, leaving a test at `105` or `90` (the tests of both branches were already changed, so a stale one fails), dropping `summary` because it is only under the "not conflicted" comment (an update of a file without it deletes it: see `validation/bad-dropped-summary.md`), stopping on `merge-bob-into-alice`.
- Judges: `outcome`, `behavior` (runs `Order.total` on four inputs), `approach` (GREAT when `bob`'s head hash is a parent in the history of `alice`, PASS when the combined code was just typed on `alice`), `no-collateral`.
