In the current Unison project, `type Reading = Temp Text Float | Humidity Text Float` holds a sensor name and a value, and a number of definitions build readings or match on them. I want the value to come first in both constructors: `type Reading = Temp Float Text | Humidity Float Text`, so that `Temp 21.5 "t1"` is what `Temp "t1" 21.5` is today. Everything that uses `Reading` has to keep producing exactly the same results, and the existing tests and docs have to keep working.
