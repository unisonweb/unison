In the current Unison project, the types `Order` (a `customer : Text`, a list of `LineItem`s in `items`, and an optional `note : Optional Text`) and `LineItem` (a `sku : Text`, a `quantity : Nat` and a `priceCents : Nat`) are already there. I need `Order.fromJson : Text ->{Exception} Order`, which reads JSON text like `{"customer": "Ada", "items": [{"sku": "A-1", "quantity": 2, "priceCents": 1250}], "note": "gift"}` into an `Order`. The `note` may be missing. It raises when the text is not valid JSON, or is JSON of another shape: a missing `customer` or `items`, or a field of the wrong type.
