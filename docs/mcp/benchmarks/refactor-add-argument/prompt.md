In the current Unison project, `bullets : [Text] -> Text` renders a list of items as bullet lines, and a number of definitions use it. I want it to take a limit as a new first argument, `bullets : Nat -> [Text] -> Text`: `bullets limit items` shows at most `limit` items, and when some are left out the output ends with one more line, `... and N more`, where `N` is how many were left out. For example, `bullets 2 ["a", "b", "c", "d"]` is `"- a\n- b\n... and 2 more"`. When nothing is left out the output is what it is today. Everything that already uses `bullets` has to keep producing exactly the output it does now, so those uses pass `maxNat` (no limit), and the existing tests and docs have to keep working. Add a test for the limit too.
