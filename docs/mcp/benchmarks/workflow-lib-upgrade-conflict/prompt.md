In the current Unison project, the code uses the library `mylib`, installed in `lib` as `mylib_1_0_0`. Version 2.0.0 is in `lib` as well, as `mylib_2_0_0`. It changes how options are passed: `Opt` has a second field and `greet` takes another argument (the library's `migration` text says how the old calls map onto the new ones). I want the project's code moved over to 2.0.0, with the old copy removed from `lib`. The behavior must not change: `welcome "bob"` is `"Hello, bob"` and `shout 2 "bob"` is `"Hello, bob Hello, bob"`. The existing tests must keep passing, with their expected values as they are.
