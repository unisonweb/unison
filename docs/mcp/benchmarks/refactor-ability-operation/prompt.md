In the current Unison project, the ability `Journal` has one operation, `entry : Text ->{Journal} ()`, and there are several handlers for it. I want a second operation, `warn : Text ->{Journal} ()`. In every handler, `warn message` has to do what `entry ("WARN: " ++ message)` does: the collecting handler records `"WARN: " ++ message`, the printing one prints that line, the handler that forwards to another ability forwards that text, and the one that ignores entries ignores warnings too. Then change `Inventory.audit` so that an item that is out of stock (quantity 0) is reported with `warn` instead of `entry`, with the same message as now; everything else it records stays as it is. Add a test for the new operation, and keep the existing tests working.
