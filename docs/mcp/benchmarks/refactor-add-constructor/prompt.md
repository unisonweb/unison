In the current Unison project, `Shape` has the constructors `Square`, `Rect` and `Circle`, and a number of functions work on shapes. I want a new constructor, `Shape.RightTriangle Float Float`, whose fields are the lengths of the two legs. Every function that works on a `Shape` has to give the right answer for it. For a right triangle with legs `a` and `b`: the area is `a * b / 2`, the perimeter is `a + b` plus the hypotenuse, it has 3 corners, its name is `"right triangle"`, scaling by `k` multiplies both legs by `k`, and it is described as `"a right triangle with legs 3.0 and 4.0"` for the legs `3.0` and `4.0`. Add tests for it too, and keep the existing tests working.
