In the current Unison project, `Log.line : Text -> Nat -> Text -> Text` formats a log line from a level, a numeric code and a message, and a number of definitions use it. I want the code to come before the level: swap its first two arguments, so that it is `Log.line : Nat -> Text -> Text -> Text` and `Log.line 42 "WARN" "disk low"` is `"[WARN 42] disk low"`, as `Log.line "WARN" 42 "disk low"` is today. Everything that uses it has to keep producing exactly the same output, and the existing tests and docs have to keep working.
