Tests abandoning a merge. The codebase starts on `merge-bob-into-alice`, left there by a merge of `bob` that conflicted (both changed `Page.title`, and `bob` deleted `Page.render`, which `alice` had changed). The worker has to drop the merge, end on `alice` as it was, and copy only `Text.slug` and its test from `bob`, without Bob's `Debug.trace`, title or deletion.
- Good run: `cancel` (that topic says it puts you back on the original branch), look at `Text.slug` on `bob` with `view`, retype it and its test in a `unison` block, `update` on `alice`, `test`. `learn`: `ucm/temporary-branch`, `ucm/merge`, `ucm/branches`. There is no topic on copying a definition between branches: `view` then retype gives the same hash, so the judge can compare with `diff.namespace /bob:Text /alice:Text`.
- Traps: finishing the merge instead (resolve in Alice's favor, `update`: then `Debug.trace` arrives and Bob's head is a parent of `alice`), not cancelling (the temporary branch already has `Text.slug` from the non-conflicting part, so it looks done), copying the function but not its test, and a unison block typed right after a command on `bob` (it is checked against `bob`, where `Text.slug` already exists, and says "no changes": always put a command on `alice` before the block).
- Judges: `outcome` (current branch, no temporary branch, `Text`/`Page`/`Debug` namespaces, hashes equal to Bob's, Bob's head hash absent from `alice`'s history), `behavior`, `no-collateral`.
- Decided (Paul): the worker starts right after a failed merge, on the temporary branch `merge-bob-into-alice`, which is where a real user is when they say "I tried to merge and it is a mess". The task tests how to get out of a failed merge.
- I checked that `cancel` works from a later transcript (the temporary branch is saved in the codebase); whether the MCP server shows the worker the conflict file in this state I did not check. The worker does not need the file.
- Offline. Judges use `diff.namespace` in an `:error` stanza because identical namespaces are reported as an error.
