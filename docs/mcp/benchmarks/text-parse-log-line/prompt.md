In the current Unison project, I need a record type `LogLine` with fields `level : Text`, `hour : Nat`, `minute : Nat` and `message : Text`, and `LogLine.parse : Text -> Optional LogLine` that parses a line of the form `[LEVEL] HH:MM message`. For example, `LogLine.parse "[ERROR] 12:30 disk full"` is a `LogLine` with level `"ERROR"`, hour `12`, minute `30` and message `"disk full"`. A line of any other shape gives `None`. Add it to the codebase, with tests.
