In the current Unison project, I need `firstDone`, which takes a list of delays in milliseconds. It starts one task per delay; each task sleeps for its delay and then returns that delay. `firstDone` returns the result of whichever finishes first, and cancels the others, so it returns quickly. For example, `firstDone [300, 50, 900]` is `50` after about 50 milliseconds, not 900. Use base's structured concurrency; nothing may be left running when it returns. Add it to the codebase, with tests.
