In the current Unison project, I need `factorialDigitSum : Nat -> Nat`, the sum of the decimal digits of `n!` (n factorial). For example, `10! = 3628800`, whose digits sum to `27`, so `factorialDigitSum 10` is `27`. `n` can be large (a few hundred or a thousand), so `n!` is far beyond 64 bits, and the answer must be exact. It should run in a few seconds. Add it to the codebase, with tests.
