In the current Unison project, `Text.slug : Text -> Text` turns a title into a URL slug, and several definitions use it. Change it so that a run of several dashes collapses into one and dashes at the start or the end are dropped: `Text.slug "  Hello --  World! "` is `"hello-world"`, and `Text.slug "a - b"` is `"a-b"`. Everything that uses it keeps its type and goes on working. Add tests for the new cases.
