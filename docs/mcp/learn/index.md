Unison is a statically-typed functional language whose code lives in a [codebase](learn:ucm/codebase), a database of definitions, not in text files. You work with it through [UCM](learn:ucm), the Unison Codebase Manager, an all-in-one tool which handles code versioning, parsing, typechecking, building, running, testing, looking up documentation, searching the ecosystem, and so on. This server lets you interact with UCM via [transcripts](learn:ucm/transcript): Markdown documents of commands and code that UCM runs and fills in with its output.

Ask `learn` for a topic by path, for example [`ucm/merge`](learn:ucm/merge). Each topic gives a short summary and an index of its subtopics, and adding `/detail` to the path gives the long version. An empty path gives this overview.
