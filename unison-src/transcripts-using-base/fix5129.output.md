Checks for some bad type checking behavior. Some ability subtyping was
too lenient when higher-order functions were involved.

``` unison :error
foreach : (a ->{g} ()) -> [a] ->{g} ()
foreach f = cases
  [] -> ()
  x +: xs ->
    f x
    foreach f xs

forkIt : '{IO} () ->{IO} ()
forkIt e =
  _ = IO.forkComp e
  ()

thunk : '{IO,Exception} ()
thunk = do
  raise (Failure (typeLink MiscFailure) "thunk" (Any ()))

go = do
  foreach forkIt [thunk]
```
