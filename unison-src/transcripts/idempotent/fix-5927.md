``` ucm :hide
scratch/main> builtins.mergeio lib.builtin
```

`update` now disallows you from editing the `lib.*` namespace. Here's what happens when you try to add something:

``` unison
lib.something = 17
```

``` ucm :added-by-ucm
  Loading changes detected in scratch.u.

  + lib.something : Nat

  ⚠️

  Your scratch file has edits to the following definitions:

    lib.something

  Modifying definitions in `lib` is not allowed.
```

``` ucm :error
scratch/main> update

  ❗️

  Your scratch file has edits to the following definitions:

    lib.something

  Modifying definitions in `lib` is not allowed.
```

And similarly, when you try to edit something:

``` unison
lib.builtin.Boolean.not : Boolean -> Boolean
lib.builtin.Boolean.not = cases
    true -> false
    false -> true
```

``` ucm :added-by-ucm
  Loading changes detected in scratch.u.

  ~ lib.builtin.Boolean.not : Boolean -> Boolean

  ~ (modified)

  ⚠️

  Your scratch file has edits to the following definitions:

    lib.builtin.Boolean.not

  Modifying definitions in `lib` is not allowed.
```

``` ucm :error
scratch/main> update

  ❗️

  Your scratch file has edits to the following definitions:

    lib.builtin.Boolean.not

  Modifying definitions in `lib` is not allowed.
```

As a convenience, if you `edit` something in `lib`, but don't change it, you don't get a warning on slurp, and it
doesn't prevent `update` from succeeding:

``` unison :hide
foo = 17
```

``` ucm :hide
scratch/main> update

scratch/main> move foo lib.foo
```

``` unison
lib.foo = 17
bar = 18
```

``` ucm :added-by-ucm
  Loading changes detected in scratch.u.

  + bar : Nat

  (and 1 unchanged term)

  Run `update` to apply these changes to your codebase.
```

``` ucm
scratch/main> update

  Okay, I'm searching the branch for code that needs to be
  updated...

  Done.
```
