Docs should show record types with their field names, as `view` does, also when the type lives in a namespace.

``` ucm :hide
scratch/main> builtins.mergeio lib.builtin
```

``` unison :hide
type Record = { name : Text, age : Nat }
type foo.bar.Nested = { x : Nat, y : Text }

recordDoc = {{ @source{type Record} }}

nestedDoc = {{ @source{type foo.bar.Nested} }}
```
