This transcript demonstrates that Unison forces actions in blocks to have a return type of `()`.

This works, as expected:

``` unison
structural ability Stream a where emit : a -> ()

ex1 = do
  Stream.emit 1
  Stream.emit 2
  42
```

This does not typecheck, we've accidentally underapplied `Stream.emit`:

``` unison :error
ex2 = do
  Stream.emit
  42
```

``` ucm :added-by-ucm
  Loading changes detected in scratch.u.

  I found an action in a block with a type of:

      a ->{Stream a} Unit

      2 |   Stream.emit
      3 |   42

  All actions are expected to have a type of Unit to catch
  accidental delayed values. To explicitly ignore a result, use:

      _ = <expr>
```

We can explicitly ignore an unused result like so:

``` unison
ex3 = do
  _ = Stream.emit
  ()
```
