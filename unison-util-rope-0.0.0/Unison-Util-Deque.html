fromListN :: Int -> [a] -> Deque a Source #

fromList for a list whose length is known. O(n). Exactly n elements are taken; a shorter list is an error. (unsafeFromListN is the same without the check, for a caller that built the list to length.)

unsafeFromListN :: Int -> [a] -> Deque a Source #

fromListN for a list known to have exactly n elements. O(n). Builds the levels directly: each gets a prefix of two to nine items and a suffix of five, and what is between them goes, in nodes of eight, to the level below. The count is trusted: with more elements than n the suffix holds them all while the packed count says five, and a later append writes outside an array.
